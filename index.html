🔑 Strong Password কীভাবে তৈরি করবেন?

Strong password শুধু random symbol দিলেই হয় না। এটি দীর্ঘ, unique এবং অন্য account-এর password থেকে আলাদা হওয়া উচিত।

❌ দুর্বল উদাহরণ

12345678
password123
rabin123
rabin@123

⚠️ শুধু শেখার জন্য sample

rabin@12#das

এই sample password বাস্তবে ব্যবহার করবেন না। Website-এ প্রকাশিত কোনো password কখনো নিজের password হিসেবে ব্যবহার করবেন না।

✅ ভালো password structure

একটি দীর্ঘ ও unique passphrase ব্যবহার করতে পারেন। যেমন কয়েকটি unrelated শব্দের সাথে সংখ্যা ও symbol।

উদাহরণ: River!Mango#27Cloud

এটিও শুধু example — নিজের জন্য আলাদা password তৈরি করুন।

🛡️ Password Rules

  • কমপক্ষে 12–16 characters রাখার চেষ্টা করুন।
  • প্রতিটি গুরুত্বপূর্ণ account-এ আলাদা password ব্যবহার করুন।
  • নিজের নাম, জন্মতারিখ, phone number ব্যবহার করবেন না।
  • একই password Facebook, Gmail, Instagram-এ ব্যবহার করবেন না।
  • OTP বা password কারও সাথে share করবেন না।
  • সম্ভব হলে password manager ব্যবহার করুন।
  • গুরুত্বপূর্ণ account-এ 2FA চালু করুন।
